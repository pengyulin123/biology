五步开通云同步

不用改任何文件。按顺序做完，回到首页点「登录」就能用。 全程免费，不需要信用卡。

正在检查配置…
1

注册 Supabase

打开 supabase.com，点右上角 Start your project，用 GitHub 账号登录（你已经有 pengyulin123，最省事）。

打不开就先解决网络，后面的步骤都依赖它。

2

建一个项目

点 New project，填三个值：

Namebiolab
Database Password自己设一个，记下来
RegionSingapore

点 Create 后等 1—2 分钟，让数据库初始化。

3

跑两段 SQL

左侧点 SQL Editor → New query，粘贴下面第一段，点 Run。 成功会显示 Success. No rows returned。

create table if not exists public.user_data (
  user_id uuid primary key references auth.users(id) on delete cascade,
  data jsonb not null default '{}'::jsonb,
  updated_at timestamptz not null default now()
);

alter table public.user_data enable row level security;

drop policy if exists "own data" on public.user_data;

create policy "own data" on public.user_data for all
  using (auth.uid() = user_id)
  with check (auth.uid() = user_id);

再点 New query，粘贴第二段，同样 Run。

insert into storage.buckets (id, name, public, file_size_limit)
values ('biolab-files', 'biolab-files', false, 52428800)
on conflict (id) do nothing;

drop policy if exists "own files" on storage.objects;

create policy "own files" on storage.objects for all
  using (bucket_id = 'biolab-files' and (storage.foldername(name))[1] = auth.uid()::text)
  with check (bucket_id = 'biolab-files' and (storage.foldername(name))[1] = auth.uid()::text);

手机粘贴长文本容易漏行，第一段共 4 条语句、第二段 3 条，都以分号结尾

4

复制两个值填进来

左侧最下面 Project Settings（齿轮）→ API，复制 Project URL 和 anon public 那串长 key。

只填 anon 那个。service_role 绝对不要填，那个能绕过所有权限。

5

关掉邮箱验证（省事）

Supabase 左侧 Authentication → Providers → Email， 把 Confirm email 关掉并保存。

不关的话，每次注册都要去邮箱点确认链接才能登录。

然后回 首页，右上角点「登录」→「去注册」，填邮箱和密码即可。

国内访问提醒　supabase.co 在部分网络下会慢或不通。 如果第 4 步「测试连接」一直失败，先用浏览器打开 supabase.com 看看能不能访问——打不开就是网络问题， 换网络（切流量/换 WiFi）再试。
